# NorthCUA Technical Report: Turbocharging Computer-Use Agents through Experience at Scale

## Abstract Summary
NorthCUA's Experience Flywheel supplies tasks to a harness that records decisions and checks outcomes, then curates verified trajectories. Unsolved tasks recurse into reusable skills. Staged Learning mixes grounding, mid-training, long-horizon SFT, and joint desktop-web RL. Nano/Mini/Pro report open-source SOTA under the paper's settings, not OSWorld 2.0 paper-protocol numbers.

## Key Contributions
1. Experience-flywheel CUA with staged grounding, SFT, and desktop-web RL.

## Empirical Highlights
Open-source SOTA under reported GUI grounding / desktop / web settings. Ultrafast pairs direct action selection with open-ended generation on pre-RL Nano. Code beipo-ai/NorthCUA.
