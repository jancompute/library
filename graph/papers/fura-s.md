# FuRA-S: Forward-Only Block-Spectral Specialists

## Abstract Summary
FuRA-S (MobileSpec) trains 1–5 MB specialists with forward-only block-spectral evolution strategies. INT4 without weight edits. Phone-use success 6–23% → 89–100% in the paper setting.

## Key Contributions
1. Forward-only block-spectral ES specialists at 1–5 MB.
2. INT4 path that does not edit base weights.

## Empirical Highlights
Phone-use 6–23% → 89–100% with 1–5 MB specialists.
