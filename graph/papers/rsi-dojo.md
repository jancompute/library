# RSI-Dojo: Post-Train Environments for Recursive Self-Improvement

## Abstract Summary
RSI-Craft / RSI-Dojo is 281 post-train environments for recursive self-improvement. SFT on Qwen3.5-9B / Qwen3.6-35B-A3B gains +8.74 / +16.87 on PostTrainBench (29.95 / 53.29 Lite).

## Key Contributions
1. 281 RSI post-train environments.
2. SFT lifts on Qwen3.5-9B and Qwen3.6-35B-A3B PostTrainBench.

## Empirical Highlights
Qwen3.5-9B / Qwen3.6-35B-A3B +8.74 / +16.87 PostTrainBench (29.95 / 53.29 Lite).
