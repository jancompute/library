# Lessons from Luck: Do LLM-Written Lessons Carry Chance into an Agent's Next Decision?

## Abstract Summary
Self-improving agents write lessons from noisy outcomes; a lesson can carry chance into the next decision. Registered study: protocol frozen and timestamped before confirmatory calls. 256 synthetic two-tool worlds; 11 LLM endpoints.

## Key Contributions
1. Chance-carrying lessons in write-time memory; not an ACE replacement.

## Empirical Highlights
Registered protocol (doi:10.5281/zenodo.23253562). Does not retarget ACE.
