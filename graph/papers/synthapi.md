# Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis

## Abstract Summary
SynthAPI controls diversity of synthetic tool-use envs along tools, tasks, and databases. Across 458,752 tasks and 849 models, downstream generalization follows a composition scaling law: tool and database diversity overtake task count as budgets grow.

## Key Contributions
1. SynthAPI as an active synthetic tool-env plug-in on task:coding-agent-rl-environment-construction.

## Empirical Highlights
849-model scaling law: scale tools and databases, not only task count. Does not retarget method:codemidas.
