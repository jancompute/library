# ROAM-GRPO: Enforcing Reasoning Diversity in GRPO via Routed Off-mode Approach Mining

## Abstract Summary
ROAM reshapes GRPO advantages with embedding-space novelty so coverage (pass@k) does not collapse while pass@1 is trained. No public code as of 2026-11-20. Distinct from Team-GRPO, DART-ES, and DATPO.

## Key Contributions
1. Embedding-distance bonus inside a GRPO host.
2. MATH level-5 pass@16 on Qwen3.5-2B (1000-problem subset).
3. 1.5–2× embedding distance vs GRPO.

## Empirical Highlights
+4.7% pass@16 on Qwen3.5-2B MATH lvl5 (1000-problem subset). Embedding distance 1.5–2× vs GRPO.
