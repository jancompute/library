# WebAnything: From the Wild Web to Scalable Agent Environments

## Abstract Summary
WebAnything reconstructs source-grounded, resettable website environments from real URLs without per-site engineering. An Explorer-Builder captures structure and interaction outcomes; a verifier checks frozen candidates and drives local repair or recapture.

## Key Contributions
1. Automated wild-web env reconstruction for web-agent RL.

## Empirical Highlights
244 website artifacts, 14 domains, 53 categories, 12,984 executed tasks. Qwen3.5-9B REAL +9.9pp. Code github.com/china-qijizhifeng/Web-Anything. Does not retarget method:recreationworld or method:claude-computer-use.
