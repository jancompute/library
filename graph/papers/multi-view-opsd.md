# One Teacher, Many Views

## Abstract Summary
Standard privileged OPSD uses one teacher distribution over the complete reference. Multi-view OPSD reduces that reference sensitivity by mixing several realizations.

## Key Contributions
1. Multi-view OPSD as an active plug-in on task:privileged-teacher-opsd.

## Empirical Highlights
- Multiple teacher views vs one complete reference. Does not retarget method:vista.
