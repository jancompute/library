# MS-TTRL

## Abstract Summary
TTRL uses unlabeled test instances, but when several solutions are valid, generation frequency is both reward and collapse pressure. MS-TTRL targets that conflict.

## Key Contributions
1. MS-TTRL as an active plug-in on task:label-free-test-time-reasoner.

## Empirical Highlights
- Multiple-solution TTRL vs majority-vote collapse. Does not retarget method:ttpo.
